description: Implement one requirement of an approved spec with the implementer agent
argument-hint: <path to spec> <requirement id>

Spec and requirement: $ARGUMENTS

1. Read the spec. Refuse if it has no Acceptance criteria section.
2. Delegate to the `implementer` agent (from code-agents) with exactly that requirement and its acceptance criteria.
3. Report what the implementer changed and which acceptance criteria are met.
